# Art Direction

## Style Goal: Nostalgic + Modern

We want the project to feel like an early Roblox mobile experience that was carefully remade today.

### Nostalgic
- Blocky character proportions
- Simple shapes and clear silhouettes
- Classic bright but controlled color sense
- Clean early-mobile UI influence
- Stud / simple surface language in the world

### Modern
- Smooth animation and blending
- Good camera feel (spring/lag, comfortable framing)
- Responsive movement
- Polished UI transitions
- Clear visual feedback
- Stable frame rate and clean presentation

## Character

- Clearly blocky (not realistic)
- Readable at a glance
- Idle / Walk / Jump / Fall as the minimum animation set
- Name tag that is easy to read and does not feel cheap

## Camera

- Third-person follow
- Smooth, not stiff
- Player should feel in control
- Comfortable default distance and height

## UI

- Clean and slightly boxy
- Modern spacing and hierarchy
- Smooth transitions between screens
- Connection states should always be clear

## What to Avoid

- Overly realistic materials or lighting that fight the blocky style
- Noisy or cluttered UI
- Instant teleport-style movement with no weight
- Static characters with no animation
- Trying to copy current-day Roblox exactly

## Success Test

If someone plays it and thinks:
> "This feels like classic Roblox energy, but it doesn’t feel janky or unfinished."

...then the direction is working.
